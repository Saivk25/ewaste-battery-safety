# Data: where it comes from and how to rebuild it

The image datasets are public and are **not** stored in this repository. Download them into `data/raw/` with the
folder names below, then run the build scripts from the repository root.

| Dataset | Used for | Source | Folder |
|---|---|---|---|
| TrashNet (Yang and Thung, 2016) | coarse non-battery classes | github.com/garythung/trashnet | `data/raw/trashnet/` |
| Garbage Classification / Garbage-12 (Mostafa, 2021) | coarse Battery (consumer batteries) | kaggle.com/datasets/mostafaabla/garbage-classification | `data/raw/garbage12/` |
| RecyBat24 / RecyBat24-aug (Acaro Chacon et al., Sci. Data 2025) | fine Li-ion classes; Li-ion photos in coarse v2; bounding boxes | Zenodo DOI 10.5281/zenodo.13126689 | `data/raw/recybat24/`, `data/raw/recybat24_aug/` |
| Multi-modal thermal runaway dataset (Kwak et al., Sci. Data 13, 1084, 2026) | measured cell surface-temperature curves replayed through the pipeline (`src/pub_realtrace.py`) | OSF doi:10.17605/OSF.IO/C2HNQ (`Dataset_TR.zip`, 2.2 MB) | `data/raw/kwak_tr/` (unzip there) |

Build steps (seeds are fixed in the scripts):

```bash
python src/run_once_sort_datasets.py      # pool raw data into data/coarse and data/fine
python src/rebalance_coarse_MERGED.py     # MD5 de-duplicate then split (coarse)
python src/rebalance_fine_MERGED.py       # group by source photo then split (fine)
python src/build_coarse_v2.py             # add one RecyBat24 photo per item to coarse Battery -> data_v2/
python src/train_cnn.py --stage coarse --backbone EfficientNet-B0 --data-dir data_v2
python src/train_cnn.py --stage fine --backbone EfficientNet-B0
```

Sensor data are generated by `src/sensor_simulation.py`; every experiment script fixes its seeds
(canonical run 42, tuning 200-229, evaluation 100-129). Licences: follow each dataset's own licence terms; the Kwak et al.
licence is not stated on the OSF record, so the files are only cited and used locally, not redistributed here.

The YOLOv8n detector data (`data_det/`) is built by `python src/detector_yolo.py prepare` from RecyBat24-aug boxes,
battery-free coarse training photos and synthetic cluttered frames (training-split photos only).
`scripts/reproduce_all.sh` runs every experiment in order.
